## ✨ 核心特色

1. **六大分類精選收錄**
   - 💬 **對話與寫作**：ChatGPT、Claude 3.7、Google Gemini、DeepSeek R1、Perplexity AI 等
   - 💻 **程式開發**：Cursor、v0 by Vercel、GitHub Copilot、Bolt.new 等
   - 🎨 **圖像與視覺**：Midjourney、Stable Diffusion、Ideogram、Flux.1 等
   - 🎬 **影音創作**：Runway Gen-3、Suno AI、ElevenLabs、Pika Art 等
   - ⚡ **辦公效率**：Gamma、Notion AI、ChatPDF、Manus 等

2. **強大實用功能**
   - 🔍 **即時多維度搜尋**：支援名稱、標籤、功能關鍵字即時篩選
   - ⭐ **個人收藏清單**：支援瀏覽器本機收藏（LocalStorage 保存）
   - ⚡ **內建 AI Prompt 提示詞助手**：提供代碼審查、社群文案、除錯、Midjourney 繪圖等高品質模板一鍵生成與複製
   - ➕ **自訂新增工具**：可即時推薦或補充新的 AI 工具到個人導航清單中
   - 🔗 **一鍵複製與直達官網**：操作直覺、高效率

3. **現代化視覺設計**
   - 暗黑未來感科技風（Dark Mode）
   - Tailwind CSS 響應式佈局（支援手機、平板、桌機）
   - 微毛玻璃特效與平滑過渡動效
